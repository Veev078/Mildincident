# Finish Post

Local continuation of the existing Studio/native preparation and Buffer outbox. No new writer, workflow, policy, database or approval system.

Preview → **Finish Post** saves browser edits, refreshes authoritative observations, reuses a matching native package or submits the existing exact-content preparation once. Later checks only reconcile its recorded request. Closing/reopening cannot resubmit an uncertain operation. Preparation never grants image rights or approves publication.

The continuation checks selected image identity, recorded usage evidence and credit, source-bound private originals (decoded bytes/hash/dimensions), adequate resolution without enlargement, and exact native final JPEGs. An arbitrary upload cannot inherit a cleared asset’s source evidence. Missing evidence produces one specific slide issue with an in-place replacement path; the previous selection remains until a replacement is chosen, and history is retained.

The final confirmation uses the existing carousel component with the actual verified finished JPEGs and saved caption. One confirmation approves the exact facts/credits/slides and requests one unscheduled draft. The existing immutable consent, shared native claim, local outbox and independent Buffer read remain authoritative. A native acceptance is **sending**, not confirmed delivery. Subsequent checks use the recorded execution/provider ID; uncertain delivery is never automatically resent.
