## What source intake does

Publication entries remain **source leads** with quoted title/summary, original URL, feed provenance, observed time and reported publication date. A byline is not a photographer credit; publication time is not photograph time; a preview is not identity/quality/rights verification. RSS / Atom parsing rejects external-entity/DTD input, bounds the response to 1 MiB, uses no redirects/retries, and caches successful reads for 15 minutes. Failed reads preserve earlier evidence. Local source metadata and observations use the existing research SQLite store, with no new publishing database or recurring process.

The existing editorial queue freezes up to six source leads and scoped founder preferences into its native job identity/context before any dispatch. The native prompt receives them as untrusted source metadata, not generated concepts or instructions.
